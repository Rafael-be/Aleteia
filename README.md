  Este é um prjeto de pesquisa relacionado ao curso técnico em informática integrado ao ensino médio da Escola Técnica Estadual Monteiro Lobato, com finalidade únicamente acadêmica, sendo desenvolvido por Rafael Nascimento Bê e Theo Keller Paiva.
  
  O projeto se norteia pela descoberta e validação do problema da fácil propagação das fake news nos dias de hoje, devido à pluralização das redes sociais, principal meio de comunicação de informações nos dias de hoje.
  
  Por isso, a proposta feita foi do desenvolvimento de um software capaz de ler um input (texto ou imagem) e submetê-lo à uma série de testes, acadêmicamente comprovados, através de uma IA aplicada. O software contará com um site para se colocar o input ou uma extensão para acesso mais fácil e rápido, mas com menos informações e com um botão de redirecionamento para o site, podendo assim ver mais informações sobre o porquê do veredito.
1. Definição das ferramentas e tecnologias usadas no projeto.
   
  	1.1 Ferramentas para backend:
   
	Linguagem de programação - Python. Uma linguagem muito poderosa para inúmeros projetos, escalonável e também muito completa, possuindo bibliotecas robustas (como Scikit-learn, NLTK, Spacy), que facilitam o trabalho para o desenvolvimento mais completo e conciso do código. Além disso, é a linguagem "padrão" para se lidar com inteligência artificial e Processamento de Linguagem Natural (LNP).

	Flask: Framework para backend, é a estutura de software que fornece funcionalidades padrões para guiar o desenvolvimento. Esse framework conversa muito bem principalmente com NLP e também com a engine de IA que será usada, TensorFlow.

	1.2 Ferramentas para frontend:

	Estilização e estruturação da página e da extensão - HTML5 para estruturação básica da página e formulários com devidas ações, requisições e inputs. CSS com framework bootstrap para estilização da página, deixando-a interativa e tendo mais opções para deixar a página mais agradável aos olhos. JavaScript para a parte de estilização, com comandos do bootstrap para ter mais controle sobre como a página interage conforme o fluxo de navegação do usuário.
